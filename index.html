Cómo abrirlo

  1. Descarga el lanzador desde el botón.
  2. Abre la carpeta Descargas.
  3. Haz doble clic en el archivo VBS.
  4. Lee y acepta únicamente los avisos de Windows que entiendas y esperes.

No necesitas descargar por separado el BAT ni el PS1 antiguos para usar este lanzador.

Revisa el origen y el contenido del programa. No desactives el antivirus ni ignores advertencias inesperadas. Conserva una copia de seguridad. No se garantiza un aumento específico de FPS. Proyecto independiente, no afiliado a Microsoft ni a Epic Games.
